# 7.1 快速排序的描述

本节整理《算法导论》第三版习题 7.1-1 至 7.1-4。先回顾快速排序与 PARTITION，再记录划分过程、重复元素的处理、时间复杂度证明和非递增排序的修改。题意按学习讨论简述，伪代码为整理后的等价写法。

## 小节回顾

### 一次划分与完整排序

快速排序采用分治思想。对非平凡子数组 $A[p..r]$，先选一个主元，通过 PARTITION 将它放到位置 $q$，再递归排序左右两部分。

教材本节的 PARTITION 选择最后一个元素 $A[r]$ 为主元，划分后满足：

$$
\begin{aligned}
A[k]&\le A[q], &&p\le k<q,\\
A[k]&>A[q], &&q<k\le r.
\end{aligned}
$$

右边严格大于主元，是这份使用 `≤` 判断的具体实现所保证的性质；快速排序正确性只需右边不小于主元。

**一次 PARTITION 不会把左右两边内部排好。** 两边内部的顺序由后续递归完成。

```text
QUICKSORT(A, p, r)
    if p < r
        q = PARTITION(A, p, r)
        QUICKSORT(A, p, q - 1)
        QUICKSORT(A, q + 1, r)
```

对整个数组排序时，调用 `QUICKSORT(A, 1, A.length)`。每个长度至少为 2 的子数组都会重新选择自己的主元，并做一次划分；长度为 0 或 1 时停止。主元已经就位，递归区间不再包含位置 $q$。

两边递归排好后，左边内部有序，右边内部有序，且左边每个元素不大于主元、右边每个元素不小于主元，所以整体有序，无须像归并排序那样再做合并。

### PARTITION 的伪代码与两个下标

```text
PARTITION(A, p, r)
    x = A[r]
    i = p - 1
    for j = p to r - 1
        if A[j] ≤ x
            i = i + 1
            exchange A[i] with A[j]
    exchange A[i + 1] with A[r]
    return i + 1
```

- $x$ 是主元的值，扫描过程中主元保留在位置 $r$。
- $j$ 是当前正在检查的位置。
- $i$ 是已经收集好的“$\le x$ 区域”的最后一个位置，初始 $i=p-1$ 表示该区域为空。

每轮循环开始时，维持以下划分：

```text
[ A[p..i] ≤ x | A[i+1..j-1] > x | A[j..r-1] 尚未检查 | A[r] = x ]
```

若 $A[j]\le x$，先将 $i$ 增加 1，再交换 $A[i]$ 与 $A[j]$，把该元素收进左侧区域；否则只继续扫描。被交换到位置 $j$ 的旧元素已知大于主元（若是自身交换，则无需移动），因此不需要回头重查。

循环结束后，交换 $A[i+1]$ 与 $A[r]$，主元就进入两部分之间，返回 $q=i+1$。

**版本区别：** 课件也介绍了从两端扫描的划分方法。本节四题均使用上述 CLRS 单向扫描版本，不混用主元选法、返回位置或递归边界。

## 7.1-1 给定数组的一次划分

**题意：** 展示 PARTITION 对下列数组的操作过程：

$$
A=\langle13,19,9,5,12,8,7,4,21,2,6,11\rangle.
$$

**解答：** 取 $p=1,r=12$，主元 $x=A[12]=11$，初始 $i=0$。以下每行记录本轮循环执行后的数组，主元暂时保持在最后。

| $j$ | 本轮检查的值 | 操作 | 本轮结束的 $i$ | 数组 |
|---|---|---|---|---|
| 1 | 13 | 大于 11，不交换 | 0 | `13,19,9,5,12,8,7,4,21,2,6,11` |
| 2 | 19 | 大于 11，不交换 | 0 | `13,19,9,5,12,8,7,4,21,2,6,11` |
| 3 | 9 | 交换 $A[1]$ 与 $A[3]$ | 1 | `9,19,13,5,12,8,7,4,21,2,6,11` |
| 4 | 5 | 交换 $A[2]$ 与 $A[4]$ | 2 | `9,5,13,19,12,8,7,4,21,2,6,11` |
| 5 | 12 | 大于 11，不交换 | 2 | `9,5,13,19,12,8,7,4,21,2,6,11` |
| 6 | 8 | 交换 $A[3]$ 与 $A[6]$ | 3 | `9,5,8,19,12,13,7,4,21,2,6,11` |
| 7 | 7 | 交换 $A[4]$ 与 $A[7]$ | 4 | `9,5,8,7,12,13,19,4,21,2,6,11` |
| 8 | 4 | 交换 $A[5]$ 与 $A[8]$ | 5 | `9,5,8,7,4,13,19,12,21,2,6,11` |
| 9 | 21 | 大于 11，不交换 | 5 | `9,5,8,7,4,13,19,12,21,2,6,11` |
| 10 | 2 | 交换 $A[6]$ 与 $A[10]$ | 6 | `9,5,8,7,4,2,19,12,21,13,6,11` |
| 11 | 6 | 交换 $A[7]$ 与 $A[11]$ | 7 | `9,5,8,7,4,2,6,12,21,13,19,11` |

循环结束时 $i=7$，最后交换 $A[8]=12$ 与 $A[12]=11$，得到：

```text
[9, 5, 8, 7, 4, 2, 6 | 11 | 21, 13, 19, 12]
```

因此返回

$$
\boxed{q=8.}
$$

**易错点：** 题目只要求一次划分，不要求继续递归排序。最终两边内部仍然无序，并不表示 PARTITION 出错。

## 7.1-2 所有元素都相同时的返回值

**题意：** 分析 $A[p..r]$ 中所有元素都相同时，原 PARTITION 返回的 $q$；修改算法，使这种情况下返回 $\lfloor(p+r)/2\rfloor$。

### 原算法返回什么？

每个被检查的元素都等于主元，所以 `A[j] ≤ x` 每次都成立。循环执行 $r-p$ 次，$i$ 从 $p-1$ 增加到

$$
i=(p-1)+(r-p)=r-1.
$$

最后交换 $A[r]$ 与自身，返回

$$
\boxed{q=i+1=r.}
$$

例如，`[5,5,5,5,5]` 中 $p=1,r=5$，循环结束后 $i=4$，返回 $q=5$。

这会使左右子问题规模分别为 $n-1$ 和 0。若继续使用原算法递归，每层都出现同样的划分，完整快速排序的耗时为 $\Theta(n^2)$。

### 修改方法

扫描时增加一个布尔变量，记录是否所有元素都等于主元。如果是，返回中点；否则保留原算法的返回值。

```text
PARTITION(A, p, r)
    x = A[r]
    i = p - 1
    all_equal = true

    for j = p to r - 1
        if A[j] ≠ x
            all_equal = false
        if A[j] ≤ x
            i = i + 1
            exchange A[i] with A[j]

    exchange A[i + 1] with A[r]

    if all_equal
        return floor((p + r) / 2)
    return i + 1
```

**正确性：** 若并非所有元素都相同，执行的交换与原算法相同，返回值也相同。若所有元素相同，任何位置的值都等于主元，返回中点时左右两边都满足排序所需的非严格大小关系，无须额外交换。

注意，全相等分支不再保持原实现“右边严格大于主元”的性质，但仍满足快速排序所需的“右边不小于主元”，因此可以直接配合原 QUICKSORT 的递归边界使用。

**复杂度：** 每轮只增加常数次操作，一次划分仍为 $\Theta(n)$，额外空间为 $\Theta(1)$。全相等输入改为近似对半递归，完整排序耗时为 $\Theta(n\lg n)$。该修改只特殊处理全相等子数组，不保证所有含重复值的输入都能均衡划分。

**易错点：** 不能对任意输入都直接返回中点，因为一般情况下中点并不满足主元与左右元素的大小关系。本题可以这样做，依赖的是“所有元素都相同”这一条件。

## 7.1-3 一次划分的时间复杂度

**题意：** 证明在规模为 $n$ 的子数组上，PARTITION 的运行时间为 $\Theta(n)$。

**证明：** 令 $n=r-p+1$。循环变量 $j$ 从 $p$ 遍历到 $r-1$，恰好执行 $n-1$ 轮。

- 每轮执行常数次操作，包括循环控制、比较，以及至多一次下标更新和交换，所以循环总时间为 $O(n)$。
- 不论输入如何，每轮都必须检查当前元素，即使一次交换都不发生，也要完成 $n-1$ 次比较，所以循环总时间为 $\Omega(n)$。
- 循环外的初始化、最后交换和返回均为 $\Theta(1)$。

结合上下界，得到

$$
\boxed{T_{\mathrm{PARTITION}}(n)=\Theta(n).}
$$

**易错点：** 这是一次 PARTITION 的耗时，不是完整 QUICKSORT 的耗时。完整排序还包含后续所有递归调用。

## 7.1-4 改为非递增排序

**题意：** 修改 QUICKSORT，使其按非递增顺序排序。

**修改：** QUICKSORT 的递归结构保持不变，将其调用的 PARTITION 改为以下版本：

```text
PARTITION-DESC(A, p, r)
    x = A[r]
    i = p - 1
    for j = p to r - 1
        if A[j] ≥ x
            i = i + 1
            exchange A[i] with A[j]
    exchange A[i + 1] with A[r]
    return i + 1

QUICKSORT-DESC(A, p, r)
    if p < r
        q = PARTITION-DESC(A, p, r)
        QUICKSORT-DESC(A, p, q - 1)
        QUICKSORT-DESC(A, q + 1, r)
```

与原始算法相比，实质变化只有把元素与主元的比较从 `≤` 改为 `≥`。递归条件 `p < r` 不变，因为它判断区间是否至少有两个元素，与排序方向无关。

### 为什么可以保证整体非递增？

一次修改后的划分只能得到：

```text
[ ≥ 主元的元素 | 主元 | < 主元的元素 ]
```

它仍然不能保证两边内部有序。完整的正确性来自递归：

1. 长度为 0 或 1 的子数组天然有序。
2. 对更长的子数组，假设递归能将较短的左右部分分别排成非递增顺序。
3. 左边每个元素都不小于主元，右边每个元素都小于主元，所以左右部分排好后，连同中间的主元，整个子数组也非递增。

例如，对 `[3,1,4,2]`，第一次取 2 为主元：

```text
第一次划分： [3, 4 | 2 | 1]
左边递归：   [4 | 3]
最终结果：   [4, 3, 2, 1]
```

**易错点：** 完整快速排序会多次选择主元；每个长度至少为 2 的子数组都要执行一次划分。不能只做最外层的一次划分便认为排序结束。“非递增”允许相邻元素相等，例如 `[4,4,2,1]`。
