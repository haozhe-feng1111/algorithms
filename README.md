- 数组下标从 1 开始，与教材一致。
- 堆的高度按根到最深叶结点的边数计算；单结点堆的高度为 0。
- $\lg n=\log_2 n$。
- 讨论含 $n$ 个元素的非空堆时，$n\ge1$。
